How to use LabelPress

1. Type your labels

Write one label per line. For a smaller second line add a bar: Rice | Jasmine or Merry Christmas! | To: Emma. Need the same label many times? Set Copies of each. Or start from an example (pantry jars, spices, storage boxes, gift tags).

2. Choose your label sheet

Pick the label sheet you bought – the number is printed on the package (for example Avery 22807 round labels or Avery 5160 address labels). Used some labels on a sheet already? Click the first free label on the preview (or choose Start at label) and LabelPress skips the used ones.

3. Make it pretty

Choose a design, the letters, a small picture and your colours. The preview shows exactly what will be printed.

4. Print

Click 🖨 Print labels. In the print window set Scale: 100 % (or "Actual size") – never "Fit to page" – and choose the paper size of your sheet (Letter or A4). For glossy labels choose a photo or label paper type in the printer settings.

Labels a little off?

Use ☰ More → Print a test sheet on plain paper. Hold it against a label sheet in front of a window. If the boxes are a bit too far right or down, move them with Fine-tune the print position (in millimetres) and try again. LabelPress remembers this setting.

Free and Pro

Free: all standard label sheets, three designs, four pictures, one sheet per print. Pro (one-time purchase, no subscription): all sheets in one go, five more designs (Farmhouse kraft, Chalkboard, Botanical, Christmas, Kids), twelve more pictures and any label size.
